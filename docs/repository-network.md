# Das Netz der Repositories

Dieses Repository ist das **Dach**. Es beschreibt, wie die Teile zusammenhängen; die Teile selbst haben eigene Repositories, damit ein Thema an einer Stelle gepflegt wird und nicht an fünf.

## Der Weg durch die Themen

```
  Inventar -> Einstufung -> Pflichten -> Nachweise -> Betrieb
```

| Schritt | Repository | Beantwortet |
|---|---|---|
| Inventar | [KI-Inventar](https://github.com/SimpleAct-Compliance/simpleact-ai-system-inventory) | Welche Systeme gibt es, auch die eingebetteten? |
| Inventar | [Anbieterregister](https://github.com/SimpleAct-Compliance/simpleact-model-vendor-register) | Wer liefert das Modell, und was hat er zugesagt? |
| Einstufung | [Risikoeinstufung](https://github.com/SimpleAct-Compliance/simpleact-ai-risk-classification-eu) | Welche Klasse gilt je Einsatzzweck? |
| Pflichten | [Prüfliste AI Act](https://github.com/SimpleAct-Compliance/simpleact-ai-act-checklist) | Was folgt je Klasse, in welcher Reihenfolge? |
| Pflichten | [Einstieg EU AI Act](https://github.com/SimpleAct-Compliance/simpleact-ai-act-compliance-guide) | Wo fängt man an, ohne alles gleichzeitig zu tun? |
| Nachweise | [Dokumentationsvorlage](https://github.com/SimpleAct-Compliance/simpleact-ai-act-documentation-template) | Was gehört in die technische Dokumentation? |

| Nachweise | [Audit-Vorbereitung](https://github.com/SimpleAct-Compliance/simpleact-ai-audit-readiness) | Was verlangt eine Prüfung, und woran scheitern Organisationen? |

| Betrieb | [Vorfallmanagement](https://github.com/SimpleAct-Compliance/simpleact-incident-management) | Art. 72 und 73: erkennen, bewerten, melden |

## Die Regel, die das Netz zusammenhält

**Ein Thema, ein Ort.** Derselbe Inhalt an zwei Stellen veraltet an einer von beiden. Dieses Repository verweist deshalb, statt nachzuerzählen — und die Einzelrepositories verweisen hierher für den Zusammenhang.

Das war früher anders: Es gab die Vorgabe, wiederkehrende Formulierungen als beabsichtigt zu behandeln. Das Ergebnis waren Repositories mit identischem Text und unterschiedlichen Titeln. Siehe [Redaktionsregeln](./editorial-principles.md).

## Tarifgenaue Anbieterangaben
