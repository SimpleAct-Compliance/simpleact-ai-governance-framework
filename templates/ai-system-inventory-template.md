# Vorlage: KI-Inventar

Ein Eintrag **je System und Einsatzzweck**. Ein Werkzeug, das in drei Fachbereichen für drei Zwecke läuft, braucht drei Einträge — die Einstufung und die Betroffenen unterscheiden sich.

Leerfelder sind kein Ergebnis. Was nicht bekannt ist, bekommt „nicht bewertet" plus Person und Termin.

---

## Identität

| Feld | Eintrag |
|---|---|
| Kennung | |
| Einsatzzweck (ein Satz: was tut es im Betrieb?) | |
| Werkzeug / Produkt | |
| Fachbereich | |
| In Betrieb seit | |
| Status | geplant / Pilot / in Betrieb / abgeschaltet |

„Pilot" ist kein Schutzraum: Wenn Beschäftigte das System im Alltag benutzen, ist es in Betrieb genommen.

**Modell und Version** ist das Feld, das am häufigsten leer bleibt und am teuersten fehlt: Ohne es lässt sich ein stiller Modellwechsel nicht feststellen.

## Daten

| Feld | Eintrag |

| Datenarten | |

„Unbekannt" bei der Trainingsfrage ist ehrlich und häufig. Es gehört mit der Fundstelle belegt, an der der Anbieter sich nicht äußert.

## Betroffene und Wirkung

| Feld | Eintrag |
|---|---|
| Betroffenenkreis | |
| Was die Ausgabe auslöst | |
| Berührt Beschäftigung, Bildung, Kreditwürdigkeit, Strafverfolgung, Migration, Justiz, wesentliche Dienstleistungen oder kritische Infrastruktur? | ja / nein |

Ein Ja in der letzten Zeile ist der Fall, in dem eine Organisation nach Art. 25 unbemerkt zum **Anbieter** eines Hochrisikosystems werden kann.
