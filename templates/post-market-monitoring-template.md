# Vorlage: Beobachtung nach dem Inverkehrbringen

Nach **Art. 72** müssen Anbieter von Hochrisikosystemen ein System zur Beobachtung nach dem Inverkehrbringen unterhalten. Diese Vorlage ist auch für Betreiber brauchbar: Die gleichen Beobachtungen sind die Grundlage, um einen Auslöser überhaupt zu bemerken.

**System / Einsatzzweck:** ___  **Rolle:** Anbieter / Betreiber  **Zeitraum:** ___  **Verantwortlich (Person):** ___

---

## 1 Was beobachtet wird

Nicht alles ist beobachtbar. Für jede Zeile gehört eingetragen, **woher** die Zahl kommt — eine Kennzahl ohne Quelle ist eine Schätzung.

| Gegenstand | Quelle | Wert im Zeitraum |
|---|---|---|
| Nutzungsvolumen | | |
| Ausgaben, die geändert oder verworfen wurden | | |
| Beschwerden oder Rückmeldungen Betroffener | | |
| erkannte Fehlfunktionen | | |
| Abweichungen im Testsatz | | |
| Modell- oder Versionswechsel beim Anbieter | | |
| Ausfälle und Einschränkungen | | |

Die zweite Zeile ist die wichtigste und wird am seltensten erhoben. Sie ist die einzige Zahl, die zeigt, ob menschliche Aufsicht tatsächlich stattfindet. Fällt sie gegen Null, ist die Aufsicht formal geworden, ohne dass jemand das entschieden hätte.

## 3 Meldepflicht geprüft

Zwei getrennte Fristen, die regelmäßig vermengt werden:

| Frage | Antwort |
|---|---|
| Liegt ein schwerwiegender Vorfall nach Art. 3 Nr. 49 vor? | ja / nein |
| Wenn ja: Meldung nach Art. 73 an die Marktüberwachungsbehörde | Datum |
| Liegt zugleich eine Datenschutzverletzung vor? | ja / nein |
| Wenn ja: Meldung nach Art. 33 DSGVO, 72 Stunden **ab Kenntnis** | Datum |

Die 72 Stunden laufen ab Kenntnis, nicht ab Aufklärung. Eine unvollständige Meldung innerhalb der Frist ist richtig; eine vollständige danach ist verspätet.

Die rechte Spalte ist die lehrreichste. Steht dort über Monate nur „Zufall", fehlt kein Feld, sondern ein Verfahren.

## 5 Ergebnis des Zeitraums

- [ ] Keine Abweichung, die eine Neubewertung erfordert
- [ ] Abweichung festgestellt, Klasse unverändert — Begründung ergänzt
- [ ] Neubewertung erforderlich — verantwortlich ___, Termin ___
- [ ] Meldung erfolgt — Datum ___, Behörde ___

**Erstellt durch (Person):** ___  **Datum:** ___  **Geprüft durch:** ___

Dieser Bericht ersetzt den vorherigen nicht. Die Reihe der Berichte ist der Nachweis, dass beobachtet wurde — ein einzelner aktueller Bericht ist keiner.
